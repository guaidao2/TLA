## §0 定位（v0.2 重新定位：从"框架组装"到"公理组合"）

### 0.1 一句话定位

**一个没有全局反向传播、没有 CE/外部奖励、只有局部预测误差、自适应推理深度、容量可生长、带自模型的序列神经网络。**

### 0.2 v0.1 → v0.2 变更摘要（为什么要重写）

- **v0.1 的错误**：把公理当作 AGI 框架的组件，按"物理层/认知层/元层"三层堆叠成一个大框架。这是**死板地遵循公理**——为了完整性硬凑三层，还引入了三层之间的调度/接口复杂度。
- **v0.2 的修正**：公理是**原料**。目标是把多条公理**组合进同一个神经网络**，让每条公理占据一个**不重叠的角色**，互相咬合成一个整体——**组合出来的东西才是新的**，不是 transformer 加几个模块，也不是三层拼装。
- **组合后矛盾消失**：v0.1 里"④误差是唯一修正信号 vs 正常训练""⑦自模型 vs 世界模型"的冲突，只在拆开单测时成立；作为一个系统，每条公理各占一个角色，冲突消失（见 §1 角色表）。

### 0.3 与 NLA（v1）的关系

- NLA（`game/FakeAGI-LLM`）是**已验证的机制基建**，全部复用：STE 融合神经元（梯度界 `‖∇STE−∇soft‖≤G/(4β)e^(−|V−θ|/β)`）、生长"右上置零"保旧神经元逐位一致、稳态校准（gain 0.3→1.0）、三信号生长门、CLS 重放（P9: 99.5% vs 18.1%）。
- **TLA = NLA v2**，增量是：**误差驱动学习（无 BP）** + **自适应推理深度（会琢磨）** + **Self_Slot 自模型**。
- NLA 的两个已知短板必须在 TLA 里正面处理：① P7 负结果（在线学习速度不足，STE 信用分配是瓶颈）；② 能量=外部奖惩，未内生化。

### 0.4 新颖性声明（诚实版）

- 纯预测编码在图像尺度已被证明可训（equilibrium propagation、error highways），但**在语言/序列尺度上，一个没有全局 BP、只有局部误差、自适应深度、容量可生长、带自模型的序列模型，没有人这么干过**——这就是本项目的新东西。
- 风险也在这：**误差驱动学习在语言尺度能不能训动，正是要跑的第一判据**（见 §9 P-LEARN-3）。

## §1 公理 → 角色 映射表（v0.2 版：单一网络内的不重叠角色）

| 公理 | 角色 | 作用位置 |
|---|---|---|
| ③ 智能≡预测误差最小化 | **统一学习法则**：整个网络的能量函数（free energy）= 逐层表征预测误差 + 下一 token 预测误差；**训练与推理共享同一目标** | 全网络 |
| ④ 预测误差是唯一修正信号 | **学习规则**：局部误差驱动权重更新（无全局 BP、无外部奖励）；任务经 top-down target 注入输出层误差 | 学习环 |
| ⑤ 时间是约束 | **动力学基板**：LTC 液态时间常数细胞，状态随时间演化 | 网络本体 |
| ⑪ 能量-时间-精度 | **推理停止/预算控制**：误差小即停；预算耗尽输出 doubtful（不硬猜） | 推理环 |
| ⑦ 自模型是必然产物 | **Self_Slot**：预测"我下一刻会输出什么"——自预测误差项 + 一致性门控 | 自监督项 |
| ⑨ 路径是生长 | **容量管理**：惊奇×新奇×能量门控生长 + importance 修剪 | 结构层 |
| ①② 物质-信息/活着先决 | **安全约束**（非学习机制）：状态有界、断电=全停 | 物理安全 |
| ⑩ 价值系统初始化注入 | **初始化注入口**：稳态/存续目标作为不可变先验 | 初始化 |

**明确不单独成网的公理**：①②是物理约束不是学习机制；⑩是初始化注入口不是架构。它们以"安全约束/先验"形式存在，不参与学习主回路。

## §2 误差预测 vs 正常训练：谁用在哪儿（v0.2 关键纪律）

> 这是本版最重要的一条线。**不是"全盘误差驱动"也不是"正常训练打底"——而是按位置分工，写死。**

| 位置 | 用误差预测（公理③④） | 用正常训练（CE+BP） |
|---|---|---|
| 隐藏层表征学习 | ✅ 局部误差驱动更新（ΔW ∝ e·a，STE 处理脉冲） | ✘ 禁用全局 BP |
| 任务学习（readout 预测下一 token） | ✅ top-down target 注入输出层误差（仍是误差，非外部奖励） | ✘ 禁用 CE 损失 |
| Self_Slot 自模型 | ✅ 自预测误差项（自监督） | ✘ |
| 管理性子网（预算头/生长门/校准） | — | ✅ 可正常训练或手工规则（不参与"学习信号"主回路） |

**为什么这样分工**：主网络（表征+任务）严格误差驱动——这是验证公理③④的诚实形态；管理性子网（何时停、何时长、多确信）是"元控制"，用正常训练不污染主回路的学习信号纪律。

## §3 单一网络总览（组合体）

```
┌───────────────────────────────────────────────────────────────┐
│                Self_Slot（⑦ 自模型：预测"我下一刻的输出"）       │
│                一致性分歧 → 触发继续琢磨                         │
└──────────────────────────────┬────────────────────────────────┘
┌──────────────────────────────▼────────────────────────────────┐
│                    readout（预测下一 token）                     │
│        top-down target 注入输出层误差（任务进入点，非奖励）       │
└──────────────────────────────┬────────────────────────────────┘
┌──────────────────────────────▼────────────────────────────────┐
│           表征层叠（每层预测下一层表征，误差逐层传播）③④          │
│   z_l = F_l(z_{l-1})，e_l = 预测 − 表征（precision 加权）        │
│   ▲ 推理环：误差迭代更新 z（settling）                           │
│   ▼ 训练环：同一批局部误差更新权重（ΔW ∝ e·a，STE）              │
└──────────────────────────────┬────────────────────────────────┘
┌──────────────────────────────▼────────────────────────────────┐
│            基板：LTC 液态细胞（⑤ 时间约束，τ 自适应 ODE）        │
│            有界性（① tanh 软饱和）· 断电语义（②）              │
└──────────────────────────────┬────────────────────────────────┘
┌──────────────────────────────▼────────────────────────────────┐
│            容量管理（⑨）：惊奇×新奇×能量生长门 + importance 修剪 │
└───────────────────────────────────────────────────────────────┘
```

**两条环，同一个量驱动**（这是"组合成新东西"的核心）：

```
推理环（会琢磨）：跑网络动力学 = 最小化 free energy（逐层误差迭代下降）
训练环（会学习）：用同一批局部误差更新权重 = 让 free energy 永久更低
```

推理时你在**消除**误差，训练时你在**让误差更难出现**——同一个量（预测误差）同时是推理信号和学习信号。这是自由能原则的完整工程形态，也是它和"transformer + 自适应深度 + 自模型"那种拼接的本质区别：**这里误差就是一切，没有外部损失**。

## §4 能量函数（free energy，公理③的数学形态）

```
E = Σ_l  ‖e_l‖²                # 逐层表征预测误差（precision 加权）
  + ‖e_out‖²                   # 下一 token 预测误差（top-down target 注入）
  + λ_self · ‖Self_Slot 误差‖²  # 自模型自预测误差（⑦）
  + λ_energy · 能耗惩罚          # 能量-时间-精度权衡（⑪）
```

- **precision 加权（公理④扩展）**：`e_l` 按置信度缩放（可学习温度，主动推理式），不确定的误差放大、确信的误差缩小。
- **无 CE、无外部奖励**：任务信号 = top-down target（下一 token 的 one-hot）在输出层产生误差，误差经反馈路径逐层传播——这是标准 PCN 的任务注入方式，全程无反向传播。
- **防遗忘**：CLS 重放缓冲（复用 NLA P9 机制，99.5% vs 18.1%），混合重放新旧样本。
- **终身学习**：用的时候就在学（无训练/部署割裂）。

## §5 推理环（会琢磨）—— 自适应深度

```
z⁰ = 前向初猜（amortized 首猜，时序暖启动：μ 继承上一时刻收敛点，轨迹边界才重置）
for k = 1..K:                          # 训练时 K 小（≤4），推理时 K 按预算
    e_l = 预测 − 表征（每层）           # 不动点残差 = 预测编码误差（非线性在预测侧）
    z ← z + Δz(误差迭代，settling)      # 沿 free energy 下降方向更新，μ 自由演化（不硬压）
    precision 加权：不确信 → 先"主动采样"（读工作记忆槽）再修正
    if max‖e‖ < θ 或 ‖out_k − out_{k-1}‖ < θ_out: break   # 误差小/输出收敛 → 停（节能⑪）
    if 预算耗尽: mark_doubtful(z)       # 琢磨不透 → 输出 + 置信度标记（不硬猜）
return z, confidence
```

**关键设计点：**
1. **停止条件 = 误差阈值 + 输出收敛 + 预算上限**：内部误差（含 LTC 隐藏态重建）渐近收敛慢，但**输出通常 1–2 步即稳定**——'输出不再变化'是最直接的琢磨收益信号（实测：干净输入 median=2 步，噪声输入更长）；够不着就标记不确定（防幻觉）。
2. **doubtful 标记**：琢磨不透的输出带置信度标记——"知道自己不知道"的工程形式。**必须带校准性判据**（标记与实际错误率的可靠性曲线），否则"幻觉率下降"可能是标记得太保守。
3. **overthinking 是已知失败模式**（文献共识）：简单输入也必须低步数——P-COG-1 硬判据盯着它。
4. **DEQ 先例与陷阱**：不动点迭代天然"误差小即停"，但训练不当会退化为"solver 空转、迭代数与难度无关"——P-COG-5 判据防这个。
5. **工作记忆槽**：每 token 一个固定尺寸 latent scratchpad，corrector 跨步读写——"主动采样看一眼"写进去，修正可跨步参考。

## §6 训练环（会学习）—— 无全局 BP 的局部学习

```
两阶段（free phase → weight update）：
① free phase：给定输入 + top-down target，迭代 settle 网络最小化 E；
② weight update：ΔW_l ∝ e_l · a_{l-1}   # 局部 Hebbian 式更新，逐层独立
   脉冲路径用 STE 代理梯度（复用 NLA 梯度界）；
   误差随深度指数衰减 → Error Highways 旁路输出误差到各层（文献已验证的解法）。
```

- **无全局 BP**：权重更新只需要本层误差 × 前层活动，天然可并行、可局部、生物可塑。
- **任务学习如何发生**：readout 误差（对下一 token 的预测错误）经 top-down 路径变成各层预测，驱动各层 settle 与更新——**任务学习和表征学习被同一个原则统一**。
- **学习速度是最大风险**：NLA P7 已证明"在线单样本误差驱动学习速度不足"（STE 信用分配是瓶颈，β 权衡：小 β 梯度陡但非零域窄）。TLA 必须正面跑学习速度探针（P-LEARN-3），不回避。

## §7 基板：LTC 液态细胞（⑤ 时间是约束）

```
τ(t) = τ_min + (τ_max − τ_min)·σ(W_τ·x(t))    # 输入调制时间常数
τ(t)·dV/dt = −V + I_syn(t) + I_ext(t)         # 膜电位 ODE（离散化实现）
V = v_max·tanh(...)                           # 软饱和，有界（①）
```

- 时间作为**状态演化的约束**：序列建模 = 时间演化，不靠位置编码硬编码。
- **不做纯 ODE 求解器**（文献教训：纯 LTC 不 scale，Liquid AI 的 LFM 实际是"线性算子+门控短卷积+少量 GQA"）——离散化线性 RNN 形态落地，与注意力混合。
- **断电语义（②）**：能量耗尽 → 全网络停摆（物理崩=全崩），软衰减 + 滞回防边界抖动。

## §8 Self_Slot（⑦ 自模型）—— 重定位为压缩自模型

```
self_pred = Self_Slot(x_t)               # x_t = [obs_t, h_t]：从"自身输入状态"预测"自己会输出什么"
损失 = ‖self_pred − output_t‖²           # 自监督，无外部标签；输入不含 output（防平凡复制）
用途：
  1. 一致性门控：自模型对**训练分布外**输入的分歧大 → 自身状态异常 → 继续琢磨；
  2. 教学信号：给 amortized 首猜 predictor 一个蒸馏目标（首猜更准 → 琢磨更少步）。
```

- **与世界模型的分工**：Self_Slot 预测的是"**我自己**的输入→输出映射"（以自我为中心），不是环境——避免与 world model 撞车。
- **实测修订（跑通时发现）**：原设计"预测 output_{t+1}"的损失**不降反升**——因为下一输出≈世界动态，预测它=主线任务本身，目标越来越难；改为"从自身输入状态预测当前输出"（网络的自我映射），损失随 readout 稳定而下降（实测 0.029→0.011）。
- **价值存疑已预注册**：自监督预测可能"学到但没用"，P-META-4 判据盯着；无效则诚实降级为"表征能力记录"。

## §9 容量管理（⑨ 路径是生长）

```
生长门：grow ⟺ (avg_error > ε_e) ∧ (novelty > ε_n) ∧ (energy > ε_E)
        # 惊奇 × 新奇 × 能量——只有"新情境 + 有资源"才长（防已知情境冗余生长）
新神经元：低增益（calib_min=0.3）→ 校准期线性升到 1.0（防噪声污染，复用 NLA）
修剪：importance[i] 低于阈值且长期未激活 → zero_out
      importance 用【长时窗 / Fisher 式累积】，不用近期滑动平均
      # 关键：防"刚重放过的技能因近期不活跃被杀"（修剪与 CLS 重放打架的解法）
```

- **若 P-LEARN-3 失败**（误差驱动在语言尺度学不动）→ 记录负结果 + 归因（学习速度/信用分配），并按**预注册分支切换**到"混合模式"（正常训练打底 + 误差当推理门控，即 v0.2 §2 表中管理性子网的正常训练扩展到主网络）——**这是判据的一部分，不是偷偷改设计**；
- 若 P-COG-3 不成立（自适应推理无增益）→ 负结果记录，不硬凑；
- 若 P-META-4 无行为增益 → 降级为"表征能力记录"。

## §11 开发路线（阶梯式，每级可独立交付）

## §12 风险与未决

1. **误差驱动学习的可训练性**（最大风险）：语言尺度无 BP 学习没有先例；NLA P7 有"学习速度不足"前科。对策：L3 学习速度探针前置 + 混合模式预注册分支。
2. **信用分配效率**：STE β 权衡是 NLA 已知瓶颈（小 β 梯度陡但非零域窄）。
3. **推理环训练稳定性**：settling 梯度跨迭代传播，需 TBPTT/STE 处理；DEQ 空转风险（迭代数与难度脱钩）。
4. **overthinking**：简单输入多想 = 纯浪费；预算头 + 步数惩罚 + P-COG-1 硬判据。
5. **误差随深度指数衰减**：Error Highways 旁路是已知解法，需验证在序列尺度有效。
6. **Self_Slot 价值存疑**：判据 P-META-4 已预注册，无效则诚实降级。
7. **自适应深度伤训练吞吐**：并行度下降，用"训练 K≤2、推理 K 按预算"的不对称缓解。

## §13 与 transformer 的差异（"新在哪"的诚实边界）

| 维度 | Transformer | TLA |
|---|---|---|
| 深度 | 固定 | **误差驱动的自适应深度**（会琢磨，简单输入少想） |
| 计算分配 | 全 token 等计算 | **每 token 计算预算**（难的多想，简单的少想） |
| 学习 | 全局 BP + CE | **局部误差驱动，无 BP、无 CE/外部奖励** |
| 容量 | 参数定死 | **惊奇门控开放容量**（带校准） |
| 自模型 | 无 | **Self_Slot**（预测自己下一刻输出） |
| 记忆保护 | 无（灾难性遗忘） | **CLS 重放**（99.5% vs 18.1%） |
| 时间建模 | 位置编码 + 注意力 | **LTC 液态时间演化**（时间本身是约束） |

**不是"注意力死了"**：注意力/混合机制保留，作为基板的一部分；TLA 的新东西是**盖在基板上面的那层"会算账的推理层 + 无 BP 学习环 + 自模型"**。

**全量判据实测（v0.2，2026-08-10，pytest 25/25 全绿）：**
- **P-LEARN-3 通过**：无 BP 局部误差驱动在未见 ω 测试集上 MSE 0.480 vs 随机 0.978 vs 恒等 0.670，训练侧 0.0008——**误差驱动学习成立**（组合体地基验证）。
- **P-COG-3 负结果（预注册协议）**：推理环消融（两变体×四轴）——有捷径版未见 ω 增益 0.12%（**循环空转**：线性捷径旁路输出，settle 白跑）；无捷径版 -5.7%（**OOD 过度精化**：settle 的重建不动点与任务预测目标错位，想得越多越偏）；正证据：无捷径版分布内 +45%（**机制在承重时真实**，场地不对）。
- **P-COG-5 跷跷板发现**：有捷径版初猜≈自适应（空转镜像：循环不干活）；无捷径版初猜差 3×（摆烂镜像：全靠循环）——**"空转"与"摆烂"是同一设计的镜像失败面**。⚠️ 限定：无捷径版初猜（max_steps=0）在轨迹起点 μ=0 且 W_lin=0 时为常数偏置，"3× 摆烂"部分是结构性基线，以 fixed1（1 步 settle）作辅助对照更公允。
- **P-LEARN-1 负结果（预注册协议）**：A=弹簧 ω0.8-1.5 → B=ω3.5-4.5，保留率 ~1.5%；CLS 重放（均匀抽样+上下文忠实重放+重放专用 lr）绝对缓解遗忘 4.4×（0.064 vs 无重放 0.077）但未达 ≥95%。归因：**W_lin 共享线性映射的权重级任务冲突**——A/B 冲突映射在同一权重上互相覆盖，重放是拔河赢不了；无捷径变体无冲突（正向迁移）但基线弱。
- **P-COG-4 通过**：置信度改"误差消除率"定义后（原公式被 tol_final 缩放压扁失效）校准成立——低置信分位 MSE 5.1× 高置信；doubtful（预算耗尽∨低置信度）标记 5.3× 未标记，doubtful 率 44%。
- **P-META-1~4**：生长门三信号 ✅、校准期 ramp ✅、修剪底部 20% 无损 ✅、Self_Slot 损失下降 ✅ 但门控无行为增益（按预案降级为表征能力级）。
- **P-LEARN-2 通过**：hidden 32→128 每规则学习成本比 1.07 <2×。
- **P-COG-1 精化尝试（负发现）**：先检后琢（暖启动输出收敛提前停）可把干净 median 压到 2 但牺牲噪声差分（两者都掐到 2）；双条件版本回归 3。最终保留原停止逻辑，差分改均值签名（clean 2.67 vs noisy 3.36），干净 median=3（预算 8 内不浪费）。预注册 ≤1 保持为已知差距。

**核心统一发现（三判据指向同一根因）：**
> **线性捷径（W_lin）悖论**——单任务上它让模型易学（P-LEARN-3 通过）、输出封顶问题消失；但它是任务无关的单一线性映射，同时杀死"会琢磨"（P-COG-3 空转：settle 不改变输出）、"防遗忘"（P-LEARN-1：A/B 冲突映射权重级互覆）、"难度差分"（P-COG-2 弱化）。去掉捷径则机制真实（分布内 +45%）但学习弱、OOD 过度精化。**未来方向：任务分离容量（MoE 式专家）、推理-任务目标对齐、防过度精化停止。**

**MoE 任务分离容量实验（第三项负/部分结果，tla/criteria/moe.py）：**
> 实现无捷径 + 专家混合（共享底 + K 专家顶层 + 路由）检验修复方向。实测：① 自由能路由（重建误差最小者胜）**不分离**——两专家重建都平庸，argmin 随机翻转，r 恒卡 0.5（MoE 对称性，硬路由也破不了）；② 原型路由（输入原型就近竞争 + EMA 更新，硬路由学习用原型 argmin——终审修复，原用 fe argmin 是 bug）**分离成立**——low-vel 输入到专家 0 责任 0.57 vs high-vel 0.30（差 0.27，方向取决于种子）；③ **无捷径专家是弱学习者**：分布内 MSE ~0.11 vs 共享捷径基线 0.004（~27×）——容量分离不能治愈"无捷径弱学习"这一更基础的短板。**修复顺序修正：先解决无捷径变体的学习强度（梯度信噪比/容量/训练时长），再谈路由分离。**
> **重测解锁条件（预注册）**：当无捷径（含 MoE）变体分布内 MSE 降到 ≤0.02（接近捷径基线 0.004 的 5× 内）时，解锁重测 P-COG-3 消融与 P-LEARN-1 保留率——避免"弱学习导致的重测失败"被误读为"机制不存在"。

**原则一实验（摊销首猜 + 残差修正，tla/criteria/pr1.py / pr1_retest.py）：**
> 哲学诊断：两个优化器（快=settle / 慢=权重）抢同一目标导致分工失序。原则一把分工写死：
> 摊销首猜 W_base 对**自己的首猜误差**负责（学得快、不被 settle 稀释），残差通路（无捷径 PCN，
> 经 settle）对**总误差**负责（加性残差，settle 直接改输出，构造上不可旁路）。
> **实测裁决：**
> ① **学习强度 ✅ 解决**：分布内 MSE 0.0046（vs 无捷径 0.11，降 24×；达捷径基线 0.004 水平）
>   ——首猜通路兑现"无捷径弱学习"的修复，**解锁条件达成（≤0.02）**；
> ② **琢磨 ❌ 仍未成立且更尖锐**：困难输入（噪声/未见 ω）上 **max_steps=0（纯首猜）最优**，
>   多想反而变差（0.0966→0.1006 / 0.3976→0.4257）——settle 的重建目标与抗噪/外推目标错位，
>   从"空转"（无影响）变成"负价值"（过度精化）；
> ③ **解锁重测（正式裁决）**：P-COG-3 负结果确认（guess 0.3928 最好 vs adaptive 0.4102）；
>   P-LEARN-1 负结果确认（保留率 6.4%，重放救不回）——**摊销首猜 W_base 是任务相关线性映射，
>   重放引入权重级任务冲突**（无捷径变体反而无冲突但有正迁移）。
> ④ 对偶未解开，但失败面机制清晰：摊销通路→强学习但任务冲突；残差通路→琢磨负价值。
>   下一步方向：摊销首猜 + MoE 专家分离（W_base 按任务分离，残差通路学"首猜不够用的部分"）。

**生物学设计原则与回退实验（双过程：系统2失败→系统1兜底，tla/criteria/pr1_fallback.py）：**
> 用户提出并确认的方法论："造神经网络要在生物学基础上想原因"。原则一实测暴露的"琢磨负价值"
> 正是**缺了人类的兜底机制**——Kahneman 双过程：系统1=快直觉（摊销首猜 W_base）、
> 系统2=慢琢磨（settle）；**人琢磨错了就瞎猜（回退直觉）**。
> 工程化：推理时若 confidence 低（琢磨没进展）或 drift=‖琢磨后−首猜‖ 超限（大偏离=可疑=
> 过度精化，只信任微调）→ 输出回退到首猜。
> **实测裁决（drift_cap=0.02，有能力轴）：**
> ① 噪声轴：琢磨从**负价值翻转为正价值**——reasoned 0.1006 > guess 0.0966（负），
>   fallback 0.0931 < guess（正）：微调被信任、大偏被丢弃；
> ② 分布内：fallback 0.0046 ≤ guess 0.0047（保持）；
> ③ 未见 ω 为**无能力轴**：三策略全在瞎猜水平（~0.4），fallback 救不了"谁都不会"的任务，
>   记录为限制（μ 暖启动状态携带使排序不稳定）；
> ④ **结论：P-COG-3 负结果在模型有能力轴上被翻转**——琢磨从"封闭重复（负价值）"变为
>   "保守确认（正价值）"，且绝不比瞎猜差。这是本架构第一个"负转正"的设计修正。

**遗忘修复链（定位诊断 + 突触巩固 EWC，tla/criteria/forgetting.py）：**
> 链路：定位 → 保护，每层过 P-LEARN-1 重测（保留率 ≥95%），过即停。
> **① 定位诊断**：B 训练冻结 W_base，A 保留率 6.4%→10.9%（改善有限）——遗忘**分布在全网络**
>   （首猜与残差读出都是任务相关线性映射，都会冲突），不是只住首猜；
> **② 突触巩固 EWC（生物：突触巩固/海马-皮层，Fisher 式局部 importance）**：A 训练累计每个权重
>   的更新量级 |ΔW|（全局部、无 BP）→ 归一化到 [0,1]（防无界累加导致 NaN）→ B 训练按
>   importance 把权重拉回 A 状态（pull = lr·λ·imp·(W_ref − W)），λ=10 实测标定。
> **实测裁决：P-LEARN-1 负结果翻转（第二个"负转正"）**——A 保留率 **108.6%**（无重放 101.9%，
>   EWC 本身即锚定，重放锦上添花）；学习强度保持 0.0084 <0.02；B 仍可学（0.65 vs 随机 1.02，
>   高 ω 任务对模型本质偏难）；λ>200 保护过度、λ=500 数值不稳定（NaN）。
> 至此三个核心问题：学习弱 ✅（原则一）、琢磨空转/负价值 ✅（双过程回退）、遗忘 ✅（EWC）——
>   全部有生物学依据的设计修正翻转/解决。

**机制修复记录（跑通/判据过程中发现并修正）：**
- PCN 非线性必须在**预测侧**（μ 自由演化，tanh 硬压 μ 会振荡）；readout 线性捷径原为封顶解药，实为"空转"根因（保留作默认，消融揭示其代价）；
- Self_Slot 语义修订：预测"下一刻输出"=预测世界（主线本身）损失不降反升 → 改为"从自身输入状态预测自己的输出"；
- 置信度公式修订：`1−max_err/tol_final` 被缩放压扁 → 改 `1−max_err/err_first`（误差消除率）；
