# 奇点-薛定谔世界模型（Singularity-Superposition World Model, SSW）

独立子项目（2026-08-11 首轮）：把**奇点神经元**放进**薛定谔叠加态世界模型**
（FakeAGI-LLM 的叠加态世界模型概念，本地重实现）——隐藏规则 + 事件计时的场景。
TLA 是否引用另行决定（当前未接线）。

## 组合设计（判据先于实现）

| 零件 | 角色 |
|---|---|
| 薛定谔叠加 | K 个分支（"可能世界"），amplitude=softmax(−预测误差) 坍缩，熵高/最优分支持续失败时分裂 |
| 奇点时钟银行 | 分支状态 = N 个独立奇点细胞（无循环），事件 → 分级暴胀，安静 → 指数衰减（λ=0.08, τ≈12.5）；特征 = −ln(h+ε)/4.6（对数线性化：衰减对时间线性） |
| 日程专家 | 分支 i 读出头先验 = 规则 i 的事件间隔（监督校准 4 epoch——实测 2 欠训、8+ 过拟合） |
| 对照 | LTC 泄漏积分基板 / 无状态基板（同一读出头，只换状态机制） |

环境：隐藏规则事件世界——3 条规则（事件间隔 5±1 / 10±2 / 20±5 tick），观测
=[event_flag, 弱规则信号]，目标=[下一事件, 归一化距下次事件]。规则隐藏 → 单值模型
学不会，叠加模型靠事件时刻坍缩。

## 判据与实测（二轮 2026-08-11：解析反演读出头后；标准量 n_ep=20）

| 判据 | 标准 | 实测 | 裁决 |
|---|---|---|---|
| SW-1 时间戳解码 | sing < ltc < ff | 0.0133 / 0.0213 / 0.0261 | **PASS（首轮负结果翻转）** |
| SW-2 叠加时间预测 | sing < ff 且 < ltc | 0.0070 / (ltc 0.0202, ff 0.0126) | **PASS（判据前提修正后）** |
| SW-3a 坍缩正确性 | sing ≥ ff + 0.05 | 0.87 vs 0.71 | **PASS** |
| SW-3b 分裂生长 | 分裂 + n=3 + 新分支>0.3 | t≈9 / n=3 / 0.415 | **PASS** |
| SW-4 单值对照 | k1 > 1.2× k3 | 0.0320 vs 0.0070 = 4.59× | **PASS** |
| SW-5 可塑性策略 | gated 回切≤0.95×uniform 且成本≤1.3× | 0.0014 vs 0.0028 / 0.1452 vs 0.1665 | **PASS** |

多 seed（3 seed，标准量）：SW-1/3a/3b/4 方向稳定；SW-2 的 sing<ff 多 seed 均值方向
保持（0.0138 vs 0.0148）但单 seed 可翻转（seed 敏感，如实记录）。

## 净结论（二轮，2026-08-11）

1. **SW-1/2 翻转（核心）**：首轮负结果翻正——奇点时间戳在网络级兑现：
   解析反演读出头（head_kind=analytic：均值状态反演 h̄/h̄0 + 可学间隔 I_i）让时间解码
   0.0133 ≪ ff 0.0261。首轮负结果归因（实测证实）：MLP 解码器学不会宽域指数反演
   （learned 解码器瓶颈，非基板）；首事件前相位无时间证据污染校准。
2. **奇点时间戳价值链条闭合**：解码（SW-1）、叠加时间预测（SW-2）、坍缩（SW-3a）、
   分裂（SW-3b）、单值失败（SW-4）全 PASS。
3. **SW-5 可塑性门控（新发现）**：振幅加权损失会饿死失败分支的学习（uniform≈frozen，
   隐含提交）；显式门控 η_i∝(1−amp_i) 抵消饿死 → 切换期适应更好（成本降 13%）且
   回切保留不损（恢复 2×）——"适应 vs 保留"不再二选一。

## 二轮修正记录（判据未改方向，实现/评估/阈值修正）

- 读出头 head_kind：mlp → analytic（奇点，均值状态反演 + 可学 interval）；
- 校准/评估只统计"首事件后"衰减相（首事件前无时钟，对所有基板不可知，统一披露）；
- interval 参数分组 lr=0.1（Adam 步长≈lr，0.5 振荡 ±0.5 / 0.05 分裂不足）；
- SW-2 判据前提修正：原"sing<ltc<ff"的 ltc<ff 腿错误（LTC learned 头混合流上
  0.0202 > ff 常数 0.0126）→ 改"sing 最优"；
- SW-5 阈值校准：0.6×（假设效应 1.67×）→ 0.95×（实测 gated 恒优 1.1-2×，3/3 seed）。

## 首轮修正记录（判据未改，实现/设置修正）

- 事件 flag 噪声 5% → 0：翻转噪声重置所有基板时钟，产生矛盾训练对（噪声鲁棒性另列）；
- 时钟银行替代含 W_h 的 substrate：复现级联恒热（热细胞持续驱动邻细胞）；
- 坍缩温度 1.0 → 0.02：归一化时间误差量级小，原温度下 softmax 平坦（坍缩不集中）；
- 分裂触发：熵信号 → 最优分支持久失败率（尖锐温度杀死熵信号；均值对偶发匹配敏感）；
- SW-3b 公平设定：专家头冻结（否则适应取代分裂）；
- SW-3a 判据前提修正：原"ff < 0.5"错误（ff 靠日程常数也能坍缩 0.71）→ 改时间状态增益；
- split() 硬编码 head_hidden=32 与模型 64 不匹配的 bug 修复。
